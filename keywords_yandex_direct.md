## Рекомендации по использованию в Яндекс.Директ

| Параметр | Рекомендация |
|---|---|
| Тип соответствия | Фразовое (`"ключевое слово"`) для точного таргетинга |
| Минус-слова | своими руками, DIY, видео, бесплатно, скачать, чертёж, самостоятельно |
| Стратегия | Целевая цена конверсии (CPA) или ручное управление ставками |
| Группировка | По тематическим группам (ангары, склады, производство, с/х, торговля) |
| Геотаргетинг | Вся Россия или отдельные регионы присутствия |
| Расширения | Быстрые ссылки на страницы услуг + уточнения (под ключ, гарантия 10 лет, от 3800 ₽/м²) |

> **Примечание:** Запросы группы 3 (по городам) рекомендуется выделить в отдельные кампании с геотаргетингом на соответствующий регион для повышения CTR и снижения CPC.
