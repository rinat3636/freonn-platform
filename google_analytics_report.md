## 4. Отслеживание SPA-навигации
Так как сайт работает как Single Page Application (React + Wouter), стандартный код GA4 не отслеживает переходы между страницами без перезагрузки.
- **Решение:** В файл `App.tsx` добавлен компонент `AnalyticsTracker`.
- **Результат:** При каждом изменении URL (маршрута) в GA4 принудительно отправляется событие `page_view` с актуальным URL и заголовком страницы. Это гарантирует точный подсчёт просмотров всех страниц.
